# Frontend - React.js Client

## 📋 Yêu cầu môi trường
- Node.js 18+
- npm hoặc yarn

## 🚀 Hướng dẫn khởi chạy
1. Sao chép `.env.example` thành `.env`:
   ```bash
   cp .env.example .env
   ```
2. Cài đặt các package cần thiết:
   ```bash
   npm install
   ```
3. Khởi chạy môi trường phát triển:
   ```bash
   npm run dev
   ```
Giao diện sẽ chạy tại `http://localhost:5173`.
